Usage guide

Install the package, mark a heading, and start the effect.

Quick start

Put the text directly inside a positioned element. Keep it on one line and leave overflow visible so the snow can extend above the glyphs.

npm install snow-letters
<h1 class="snow-letters">Winter Sale</h1>

<style>
  .snow-letters { position: relative; }
</style>
import { startSnowLetters } from 'snow-letters';

const stop = startSnowLetters();

Change the thickness

--snow-thickness sets depth as a fraction of the font size. It defaults to 0.16. Use 0 to hide snow on one element.

Frost

0.08

Drift

0.24

Add snow to new text

Pass a CSS selector to watch different elements. Matching elements pick up snow when they appear. Call stop() before unmounting your view or disabling the effect.

const stop = startSnowLetters({
  selector: '[data-winter]'
});

API

startSnowLetters(options?)
Starts the effect and returns a cleanup function.
options.selector
A CSS selector. Defaults to .snow-letters.
--snow-thickness
A nonnegative number, applied per element.
